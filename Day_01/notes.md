## Lecture 2: JavaScript Setup & Environment

### Key Points

* Practice coding more than theory.
* Use a proper code editor like VS Code.
* JavaScript files use the `.js` extension.
* JavaScript can run outside browsers using Node.js.
* `console.log()` is used to print output.

### Setup Steps

1. Install VS Code.
2. Install Node.js.
3. Create a `.js` file (example: `test.js`).
4. Run JavaScript using:

```bash
node test.js
```

### Example Code

```js
console.log("Hello JavaScript");
console.log("Super-20");
```

### Key Takeaways

1. VS Code improves coding efficiency.
2. Node.js allows JavaScript execution outside the browser.
3. `console.log()` helps display output and debugging.
4. Practice regularly to improve coding skills.
